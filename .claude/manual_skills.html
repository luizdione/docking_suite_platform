1. O que são "skills pessoais" e onde ficam

Uma skill é uma pastinha com um arquivo SKILL.md que ensina o Claude Code a executar uma tarefa. Quando a skill fica em C:\Users\luizd\.claude\skills\ ela é pessoal (global): vale em todos os seus projetos, não só na NQ-Docking Suite.

EscopoLocalVale para
Pessoal (global)C:\Users\luizd\.claude\skills\<nome>\SKILL.mdTodos os seus projetos
Projeto<repo>\.claude\skills\<nome>\SKILL.mdSó aquele projeto (versionado no git)

Como chamar: digite / seguido do nome da skill no Claude Code. Ex.: /salvar_contexto. Você também pode passar um foco: /salvar_contexto módulo ADMET.

2. As duas skills e o que cada uma faz

/salvar_contexto

Gera/atualiza a memória da sessão atual em arquivos Markdown do projeto (objetivo, progresso, decisões, arquivos tocados e pendências). Serve para você reduzir o contexto depois — com /compact, /clear ou /branch — sem perder a continuidade da tarefa.

Quando usar: contexto grande (perto do limite / 1M no Opus), antes de compactar/limpar/forkar, ou ao encerrar um bloco de trabalho.

/salvar_contexto_compactar

Faz o mesmo que a /salvar_contexto (grava a memória) e, no fim, entrega o comando /compact pronto (com foco) para você digitar — o fluxo "salvar e compactar" numa tacada só.

Importante: nenhuma skill executa /compact sozinha. /compact, /clear e /branch são comandos que você digita no Claude Code. A skill prepara tudo (salva a memória) e te diz o comando exato para digitar em seguida.

3. Quais arquivos .md são atualizados

As duas skills mexem nos mesmos três arquivos, sempre dentro do projeto atual:

ArquivoPapelComo é atualizado
docs/historico/CONTEXTO_SESSAO.md Arquivo vivo — estado mais recente (é o que se relê ao retomar) Sobrescrito a cada execução
docs/historico/BRIEFING_<data>_<tag>.md Snapshot datado — histórico imutável da sessão Novo a cada vez; nunca sobrescreve os anteriores
claude.md (raiz) Ponteiro de compactação Ganha a seção ## Instruções de Compactação só na 1ª vez (idempotente)

👉 Para retomar do zero, o arquivo-chave é docs/historico/CONTEXTO_SESSAO.md.

4. O hook de auto-load (memória automática ao abrir a sessão)

O projeto tem um hook SessionStart (.claude/settings.json + .claude/hooks/carregar_contexto.py) que injeta automaticamente o conteúdo de docs/historico/CONTEXTO_SESSAO.md no início de toda sessão nova, retomada, após /clear e após /compact. Se o arquivo não existir, o hook não faz nada (silencioso). Assim, ao abrir a sessão, o Claude já "lembra" onde você parou — sem você digitar nada.

Teto de segurança: o hook injeta no máximo ~20 mil caracteres, para não inflar o contexto logo na abertura. Mantenha o CONTEXTO_SESSAO.md enxuto.

6. Instalar / atualizar as skills pessoais

As skills são desenvolvidas e versionadas no repositório e depois copiadas para a sua pasta pessoal. Rode o instalador (no Windows) a partir da pasta .claude do repo:

cd "C:\Users\luizd\OneDrive\Data_Science\Projetos\docking\.claude"
.\instalar_skills_pessoais.ps1

O instalador copia salvar_contexto e salvar_contexto_compactar para C:\Users\luizd\.claude\skills\ e copia este manual para ...\Projetos\manual_skills.pdf. Para reinstalar depois de editar uma skill, é só rodar de novo (ele sobrescreve).

Como estão em escopo pessoal, as skills passam a valer em qualquer projeto seu. Dentro da NQ-Docking Suite elas também existem no escopo do projeto (repo) — funciona igual; se preferir, pode manter só a versão pessoal.
